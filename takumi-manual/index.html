1. はじめに

  • このサイトは「1回のスワイプで1ページ」進む作りです。ページの高さは画面1枚分に決まっているため、文字を増やすとはみ出すことがあります
  • ページは全部で10枚です：TOP（動画）／p1 共感／p2 アンサー／p3 仕事内容／p4 強み1／p5 強み2／p6 よくある質問／p7 会社概要／募集要項／エントリー
  • 募集要項とエントリーだけは「長いページ」で、ページの中を下へスクロールします
  • 直すファイル：index.html（文言）／assets/（画像・動画）
  • 直さないファイル：base.css（骨格）・swipe.js（ページ送り）・style.css（見た目と動きの本体）・site.js（動きの一部）。動きの数値だけを変えたいときは 7.6 の例のように tokens.css の「値」だけを変えます
  • 文言は、ヒアリングシートの原稿を一言一句そのまま載せています（掲載文言.md）。言い回しを変えるときは、原稿側も合わせて更新してください

2. 文言の直し方

2.1 基本

  • 文言は <span class="ln">…</span>（見出しの1行）や <span class="band__t">…</span>（p1 の帯）、<p class="sheet__t">（p2・p4 の本文）、<p class="txt">（p3・p5 の本文）の中にあります。タグは消さずに、中の文字だけを書き換えます
  • 改行の位置は画面の幅で自動で決まります。語の途中で切れる場合は、その句を <span class="nb">…</span> で包みます（nb の中では改行されません）
  • 太く大きくしている語は <b class="kw">…</b> です。強調の札（白地に黒字）は <span class="em" data-text="○○">○○</span> です
  • 英字のラベル・番号（page__label や num__k・num__n）は飾りです。日本語の文言は入れないでください（原稿との照合が合わなくなります）
  • <span class="vh">・</span> や <span class="vh">：</span> は、音声読み上げ用に残している記号です。消さないでください

2.4 文字数の目安

下の「現在の文字数」は、装飾の英字・番号と読み上げ用の記号を除いた、いま掲載している文字数です。この数字を大きく超えると、画面（高さ664px のスマホ）からはみ出すことがあります。増やす場合は制作者にご相談ください。

5. やってはいけないこと

  • CSS の末尾に指定を足して上書きする（後から直せなくなります）。!important を使う
  • 文字を小さくして収める（最小 13px より小さくしない）
  • 1ページの文字を大幅に増やす（はみ出します。ページを分けるか、制作者に相談）
  • tokens.css・base.css・swipe.js・style.css・site.js の中身を、この資料の 7.6 に書いた「値の変更」以外で書き換える
  • 動きを「スクロールに合わせて動く」仕組みに変える（このサイトの決まりで、動きはページに入った時に1回流す作りです）
  • 写真・動画に文字を焼き込む（スマホで切れます。文字は index.html に書きます）

6. 直した後の確認

  1. スマホ（縦）と PC で、各ページが1画面に収まっているか（文字が下や横で切れていないか）
  2. 1回のスワイプ・ホイールで1ページだけ進むか
  3. 強調の札・「40」・p3 の7つの切り替え・p5 の丸が、いつもどおりに動くか（7. の時間割と見比べる）
  4. 直した文言が、ヒアリングシートの原稿と一致しているか（制作者に依頼できる場合は照合の道具で検査します）
  5. 公開後、スマホで古い表示が残っていないか（?v= を更新したか）

7. 動きの仕様（動的箇所のマニュアル）

7.1 動きの書き方

このサイトの動きは、次の4つを言葉と数値で書き残します。コマ画像（写真のコマ送り）と数字を一緒に見れば、誰でも同じ動きを作り直せます。

  • 何が：どの部品が動くか（見出し・写真・帯・丸など）
  • どの順番で：ページに入ってから何番目に動き出すか
  • 何秒で：動き出す時刻（ページに入った瞬間を 0 とする）と、動く長さ
  • どう動くか：下から持ち上がる／左から拭き取るように出る／黒い四角が横に開く、など

時間は ms（1000分の1秒。1000ms＝1秒）で書きます。「0」はページが画面に切り替わった瞬間です。

コマ画像の見方：各ページの動きは、0／0.2／0.4／0.7／1／1.5／2／3／4 秒の9コマを横に並べた画像で示します（画像の左から順。左上の赤い数字は並び順で、時刻ではありません）。画像は幅390×高さ664px のスマホ画面で記録しています。先頭のコマは、前のページの画面が写ることがあります。

動きを作るときの流れ（制作者向け）

  1. 参考にするサイトを画面録画し、0〜4秒のコマ一覧にする（tools/refcap.mjs）
  2. コマから「何が・どの順番で・何秒で・どう動くか」を文章と数値の時間割にする（推測せず、コマで確かめる）
  3. 時間割の数値を CSS の変数（tokens.css）に置く。ページ固有の遅れは style.css のページ別の変数（--t0・--lines-delay）に置く
  4. 自分のサイトを同じ道具で記録し、参考とコマを並べて、順番・速さ・質感が合っているか確かめる

7.2 共通の決まり

  1. スクロールに連動して動かさない：動きは「ページに入った時」に始まります。スクロール位置に合わせて要素を動かす作りにはしません
  2. 1ページ約2秒以内に出そろう：最初の動き出しは 0.3秒以内（.rv の先頭は 200ms）。文字と写真は約2秒で出そろいます（下の時間割で、最長は p5 の丸の 2.3秒。飾りの線は 2.5秒前後まで続くページがあります）
  3. 順番は「写真 → 見出し → 本文 → 締め」：この順を保ったまま時間を詰めます
  4. 同じ役割の部品は同じ動き：見出しはすべて同じ打ち出し、本文の帯・段落はすべて同じ出方にそろえます
  5. 時間は変数にまとめる：tokens.css の --dur-*・--delay-* で一括調整します
  6. ブラウザで「動きを減らす」設定が入っているときは、動きを止めて文字を最初から見せます（base.css:175-178）
  7. 点滅・強い光は入れない（目がチラつかないように、黒い長方形・線・ノイズに限る）

7.6 動きを変えたいとき（3つの例）

値を変える場所は site/tokens.css の末尾近く（/* motion */ の行）の「値」だけです。変数の名前や、その行の構成は変えません。変えたら 6. の確認を行い、問題が出たら元の値に戻します。

例1：全体を速くする（出現のテンポを速める）

  • 変える：--dur-in: 500ms; → 350ms／--rise: 1.2em; → 0.8em
  • 起こること：全ページの rv（小見出し・本文・帯・表など、上から順に出てくるもの）の出現が速く、持ち上がる距離も小さくなる。p7 の「TAKUMI」の透明度にも効く
  • 変わらないもの：黒い四角の開き方・見出しの打ち出し・丸の弾み・線の走り方。これらは style.css と site.js に秒数が直接書いてあるため、速くしたいときは制作者に依頼する（7.7 の表）
  • 元に戻す：500ms／1.2em

例2：写真の出方をゆっくりにする（p1 の閃光から写真が出るまで）

  • 変える：--delay-dawn: 80ms; → 400ms
  • 起こること：p1 で、白い閃光と写真の戻りの動き出しが 320ms 遅くなり、真っ暗（白）な待ちが長くなる。小見出しの番号の出始めも同じだけ遅れる。見出し以降は変わらないので、p1 全体の出そろいは約 2.1秒 → 約 2.4秒になる（「1ページ約2秒」の決まりを超えるので、遅らせすぎない）
  • 他のページの写真（四角が開く・幕が上がる・戻り）の速さは、style.css・site.js の直接書きの値です（7.7 の表）。変えるときは制作者に依頼する
  • 元に戻す：80ms

例3：強調の札のノイズの間隔を変える

  • 変えるのは style.css の 162・172・173 行目の 5s（3か所すべてを同じ値に）です。tokens.css の変数にはなっていません（制作者が --noise-interval のような変数にすれば、1か所で直せるようになります）
  • 例：5s → 8s にすると、札の「ビビッ」と震えるノイズが 8秒に1回になる。1回のノイズの長さ（約0.18秒）は、周期の 3.6%分のため、8秒にすると約0.29秒に伸びる
  • 3か所の値が違うと、札の震えと帯のずれがずれて見えるので、必ずそろえる
  • 元に戻す：5s
