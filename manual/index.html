1．はじめに

このサイトで、ご自身で直してよいのは「目印」がついている所だけです。直せるのは次の2つです。

  • 文言（✏️）…サイトの文章。軽い言い換えや、数字・名前の変更。
  • 画像（🖼）…写真の差し替え。

目印は、index.html というファイルの中に、次のような一行で入っています。

<!-- ✏️E05 ○P 本文｜文字数の目安｜注意 --> <!-- 🖼I13 ○P 写真｜ファイル名｜縦横比・サイズ -->

✏️E＋数字が文言、🖼I＋数字が画像の番号です。目印のすぐ下（または同じ行のすぐ後）にあるものが、その番号の直す対象です。番号はこのマニュアルの画面や表にも同じものが出ています。

作業の前に、必ず控えを取ってください。

  1. 「01_PELLICULE株式会社」フォルダを、まるごとコピーします（Macは右クリック→「複製」、Windowsはコピーして貼り付け）。
  2. 名前を「01_PELLICULE株式会社_控え」のようにして、作業日を足します。
  3. 直す作業は、元のフォルダのほうで行います。

画像は「整理版」の1つ外側にある assets フォルダに入っています。「整理版」だけでなく、1つ上の「01_PELLICULE株式会社」ごとコピーしてください。

用意するもの

  • 文章を直すための編集ソフト。無料の「Visual Studio Code」が使いやすいです（Windows・Mac対応）。Macの「テキストエディット」を使う場合は「フォーマット→標準テキストにする」にしてください。Windowsのメモ帳でも直せます。
  • 確認用のブラウザ（Chrome・Safariなど）。
  • 文字コードは UTF-8 で保存します。Visual Studio Code は画面の右下に「UTF-8」と出ていれば大丈夫です。違う表示のときは、そこをクリックして「エンコード付きで保存」から UTF-8 を選びます。日本語が「???」や文字化けになったら、保存せずに控えへ戻してください。

2．文言の直し方

  1. index.html を編集ソフトで開きます。（「整理版」フォルダの中にあります。）
  2. 番号で探します。編集ソフトの検索（Windows は Ctrl＋F、Mac は command＋F）に「✏️E18」のように入れます。「✏️」が入力しにくいときは「E18 」（番号のあとに空白を入れる）だけでも探せます。
  3. 目印のすぐ下の文を、書き換えます。下の見本のように、色をつけた部分の「文字」だけを直します。< と > で囲まれた部分（タグ）は、そのままにしてください。
    <!-- ✏️E18 2P 大きな文｜現状16字→安全18字(限界39字)｜行の数は変えない・行の中で改行したい時は<br>｜「関係ない」の囲みは残す --> <p class="big kara"><span class="ln">年齢も、役職も、経験も<span class="nb"><span class="key key--big mk">関係ない</span>。</span></span></p>

    上の例は、E18（2Pの大きな文）です。「関係ない」の周りの <span class="key key--big mk"> は、文字を黄色いマーカーで強調する部品なので、消さずに残します。

  4. 保存します。（Ctrl／command＋S）文字コードは UTF-8 のままにします。
  5. ブラウザで確認します。index.html をブラウザにドラッグすると表示されます。直したページまでスワイプ（PCはスクロール）して、文が出きること、次へ進むボタン（NEXT）に被らないことを見ます。くわしくは「6．直した後の確認」へ。

文字数の目安の見方

目印と一覧表には、文字数の目安を書いてあります。文字数は、全角の1文字を1字と数えます。「、」「。」「　」も1字、半角の英数字も1字として数えます（半角のほうが幅が狭いので、安全側です）。

表示意味
現状○字→安全△字△字までなら、行が増えず、見た目がほとんど変わりません。迷ったらこの数字までにしてください。
（限界□字）その行だけを伸ばして、折り返しで行が増えても、ギリギリ被らなかった字数です。ほかの行も一緒に伸ばすと被ることがあります。
現状○字のままこれ以上は増やせません（余裕がない所です）。
被る心配なし今の文字数＋60字まで伸ばしても被らないことを確認した所です。

この数字は、スマホ（360×640、390×540）とPC（1280×720）の3つの画面の大きさで、実際に表示して測りました。ほかの大きさの画面では少し変わることがあります。画面に出ない設定（タブ名など）の字数は、一般的な目安で、実測ではありません。

行（ぎょう）と改行について

  • サイトの文章は、<span class="ln">〜</span> で1行ごとに区切ってあります。この区切り（行）の数は増やしたり減らしたりしないでください。行が増えると、画面の高さが足りなくなります。
  • 1つの行の中で、途中で改行したいときだけ、改行したい場所に <br> を入れます。ただし改行すると高さが増えるので、必ず「6．直した後の確認」を行ってください。
  • 文の中に & を書きたいときは &amp; と書きます。< や > を文字として書くことはできません。

3．画像の差し替え方

画像は、同じファイル名・同じ縦横比・同じ形式で、上書きするのがいちばん簡単で安全です。目印の文を書き換える必要はありません。

  1. 差し替えたい画像の番号を探します。このマニュアルの画面の青い番号（例：I13）か、index.html で「🖼I13」を検索します。目印の中に、ファイル名（例：assets/photo/p13.webp）、縦横比、大きさが書いてあります。
  2. 新しい写真を、同じ縦横比にします。例として I13 は「縦横比 4:3・推奨 720×539px(元と同じ)・WebP・容量72KB」です。縦横比が違う写真を入れると、枠に合わせて中央が自動で切り取られます（被写体は真ん中に入れてください）。
  3. WebP形式にします。無料のブラウザ用ツール「Squoosh」（squoosh.app）が使えます。写真を画面にドラッグし、右側の形式で「WebP」を選び、品質を75〜80くらいにして、「リサイズ」で元と同じ大きさ（幅×高さ）にそろえ、右下のダウンロードを押します。（ツールの画面は変わることがあります。表示が違うときは担当者にご相談ください。）
  4. ファイル名を元と同じにして、上書きします。ダウンロードしたファイルの名前を p13.webp のように元と同じにして、assets/photo フォルダに入れ、「置き換える」を選びます。上書きの前に、控えを取ってあることを確かめてください。
  5. ブラウザで強めに再読み込みして確認します。（Windows：Ctrl＋Shift＋R、Mac：command＋Shift＋R）古い写真が残って見えるときは、これで直ります。

知っておくと安心なこと

  • 同じ写真が、いくつかのページで使われている場合があります。ファイルを1つ上書きすると、使われているすべての場所が変わります（どこで使われているかは、一覧表と目印の末尾に書いてあります）。
  • ページに出る写真は小さいので、元より大きな写真は不要です。目安は「元と同じ大きさ」です。容量が大きすぎると表示が重くなります。元のファイルの容量（表に記載）を超えないようにしてください。
  • 使っていない写真（p15・p17・p18）が assets/photo に入っています。差し替えに使っても構いません。その場合は、使いたい場所の写真と同じファイル名にして上書きしてください。
  • TOPの動画（I20）、動画が始まる前の写真（I21）、ロゴ（I19）、シェア用の画像（I22）は、縦横比と大きさが決まっています。差し替えるときは、表の通りの大きさで作り、同じファイル名で上書きします。動画の作り直しは担当者にご相談ください。

5．やってはいけないこと

  • タグを消さない・変えない。< と > で囲まれた部分や、class="…" の中身は、見た目や動きを決める部品です。消したり直したりすると、文字が出なくなったり、レイアウトが崩れたりします。
  • 行（<span class="ln">）を増やさない・減らさない。改行したいときは <br> です。
  • 飾り（<svg>…）や、class="key"・class="mk" の囲みを消さない。マーカーや波線などの飾りです。
  • 文字数の目安（特に「安全」）を超えない。超えると、次へ進むボタン（NEXT）や、ほかの文に被ります。超えたいときは、担当者にご相談ください。
  • 目印の行（<!-- 〜 -->）を消さない。消すと、次に探せなくなります。
  • 目印のない所は触らない。背景に流れる英字、NEXTボタンの行き先の名前、色、余白、アニメーションなどは、担当者の作業です。style.css・tokens.css・script.js・pel.js は開かない・直さないでください。
  • 画像のファイル名や拡張子（.webp）を変えない。縦横比の違う写真や、大きすぎる写真を使わない。
  • 保存したあと、文字化け（？や□）が出たら、保存し直さず、控えに戻します。

6．直した後の確認

  • 文章が最後まで出る（途中で切れていない）。
  • 文が画面の右にはみ出していない。
  • 画面の右下の「NEXT」ボタンに、文や写真が被っていない。
  • 画面の上の、ロゴとボタンのある帯に被っていない。
  • 1画面（スワイプ1回分）に収まっている。
  • 直していない他のページが、変わっていない。
